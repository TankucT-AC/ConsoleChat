# Simple C++ Messenger (WebSocket)

Высокопроизводительный чат-сервер и клиент на базе протокола WebSocket. Проект демонстрирует работу с асинхронным сетевым вводом-выводом, многопоточностью и сериализацией данных в JSON

## 🚀 Ключевые особенности
* **Asynchronous IO**: Использование библиотеки `WebSocket++` на базе `Boost.Asio` для обработки множества соединений в одном событином цикле (Event Loop)
* **Multithreaded Architecture**: Разделение сетевого потока и потока пользовательского интерфейса для предотвращения фризов
* **Thread Safety**: Безопасная работа с общими ресурсами (список пользователей) с использованием мьютексов (`std::mutex`, `std::lock_guard`)
* **ANSI Terminal Control**: Динамическое обновление консоли для предотвращения разрыва строки ввода при получении новых сообщений
* **Persistent Storage (SQLite3)**: Интеграция легковесной реляционной базы данных для долгосрочного хранения переписки и предотвращения потери данных при перезапуске сервера

## 🛠 Технологический стек
* **Язык**: C++17
* **Библиотеки**: 
    * [WebSocket++](https://github.com/zaphoyd/websocketpp) — сетевой транспорт
    * [nlohmann/json](https://github.com/nlohmann/json) — работа с форматом данных
    * [Boost.Asio](https://www.boost.org/doc/libs/release/libs/asio/) — системный бэкенд для сетей
    * [SQLite3](https://github.com/sqlite/sqlite?tab=readme-ov-file) — база данных для хранения истории чата



## 🏗 Архитектура

### Серверная часть
Сервер работает в асинхронном режиме. При подключении нового клиента `connection_hdl` сохраняется в потокобезопасный контейнер `std::set`. При получении сообщения сервер транслирует его всем активным участникам, кроме отправителя

### Клиентская часть
Клиент разделен на два основных потока:
1. **Main Thread**: Обработка ввода пользователя (`std::getline`)
2. **Network Thread**: Фоновый цикл `user_client.run()`, отвечающий за получение и отрисовку входящих сообщений

## 🔧 Сборка и запуск (Linux/WSL)

1. **Установите зависимости**:
   ```bash
   sudo apt-get update
   sudo apt-get install libwebsocketpp-dev nlohmann-json3-dev libboost-all-dev libsqlite3-dev
   ```
2. **Скомпилируйте проект**:
   ```bash
   mkdir build && cd build
   cmake ..
   cmake --build .
   ```
3. **Запустите проект**:
   ```bash
   ./my_server
   ./my_client
   ```
